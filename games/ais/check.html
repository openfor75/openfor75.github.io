學生的回報碼可以從郵件複製,或從 Google 表單試算表整欄複製貼上。驗證完可一鍵複製成表格,直接貼進 Excel 登記成績。

📥 進階(選用):用 Gmail 自動把回報碼收進試算表

如果您是請學生用郵件回報,可以用這支 Google Apps Script 自動把信件裡的回報碼撈進試算表, 一位學生一列,重複寄不會重複列入,還能設定每天自動執行。
它只讀取您自己的信箱,不是對外收集資料的伺服器。

如果您改用 Google 表單讓學生送出,就完全不需要這一段——答案會直接進試算表。

  1. 開一個新的 Google 試算表
  2. 上方選單 擴充功能 → Apps Script
  3. 把預設程式碼刪掉,貼上下面整段,存檔
  4. 選 collectReports 按「執行」,第一次會要求授權,按同意
  5. (選用)左側「觸發條件」→ 新增 → collectReports → 時間驅動 → 日計時器
/**
 * 會計資訊系統 — 從 Gmail 自動收集學生的成績回報碼到試算表
 *
 * 這支腳本只讀「您自己的信箱」,不是對外收集學生資料的伺服器。
 *
 * ── 安裝(一次就好)──────────────────────────────────
 * 1. 開一個新的 Google 試算表
 * 2. 上方選單 擴充功能 → Apps Script
 * 3. 把預設的程式碼全部刪掉,貼上這一整份,存檔
 * 4. 上方選單選 collectReports,按「執行」。第一次會要求授權,按同意
 * 5. (選用)左側「觸發條件」→ 新增觸發條件 → collectReports → 時間驅動 →
 *    日計時器 → 每天跑一次,之後就完全自動
 *
 * ── 用法 ────────────────────────────────────────
 * 執行後,試算表會出現「回報碼」工作表,每位學生一列。
 * 把「回報碼」那一整欄複製,貼進老師驗證頁的「整班批次驗證」即可。
 * 同一個回報碼重複寄不會重複列入。
 * ────────────────────────────────────────────────
 */

/* ===== 可以改的設定 ===== */
var SEARCH_QUERY = 'subject:(會計資訊系統) newer_than:180d';  // 要撈哪些信
var SHEET_NAME   = '回報碼';                                  // 寫到哪個工作表
var DONE_LABEL   = '成績已收';                                // 處理過的信貼這個標籤
/* ======================= */

function collectReports() {
  var ss = SpreadsheetApp.getActiveSpreadsheet();
  var sh = ss.getSheetByName(SHEET_NAME);
  if (!sh) {
    sh = ss.insertSheet(SHEET_NAME);
    sh.appendRow(['收信時間', '寄件者', '信件主旨', '姓名', '組數', '回報碼']);
    sh.setFrozenRows(1);
  }

  // 已經收過的回報碼,避免重複
  var seen = {};
  var last = sh.getLastRow();
  if (last > 1) {
    sh.getRange(2, 6, last - 1, 1).getValues().forEach(function (r) {
      if (r[0]) seen[String(r[0]).trim()] = true;
    });
  }

  var label = GmailApp.getUserLabelByName(DONE_LABEL) || GmailApp.createLabel(DONE_LABEL);
  var threads = GmailApp.search(SEARCH_QUERY + ' -label:"' + DONE_LABEL + '"', 0, 100);
  var rows = [], found = 0;

  threads.forEach(function (th) {
    th.getMessages().forEach(function (msg) {
      var body = msg.getPlainBody() || '';
      // 回報碼格式:V1|姓名|setXX:分數:分數:日期,…|日期|XXXX-XXXX
      var hits = body.match(/V1\|[^|\r\n]+\|[^|\r\n]+\|[^|\r\n]+\|[0-9A-Z]{4}-[0-9A-Z]{4}/g);
      if (!hits) return;
      hits.forEach(function (code) {
        code = code.trim();
        if (seen[code]) return;
        seen[code] = true;
        found++;
        var p = code.split('|');
        var name = p[1];
        var cnt = p[2].split(',').filter(String).length;
        rows.push([msg.getDate(), msg.getFrom(), msg.getSubject(), name, cnt, code]);
      });
    });
    th.addLabel(label);   // 標記處理過,下次不再掃
  });

  if (rows.length) {
    sh.getRange(sh.getLastRow() + 1, 1, rows.length, 6).setValues(rows);
    sh.autoResizeColumns(1, 5);
  }

  var msg = '掃描 ' + threads.length + ' 封信,新增 ' + found + ' 筆回報碼。';
  try { ss.toast(msg, '收集完成', 6); } catch (e) {}
  Logger.log(msg);
}

/**
 * 選用:把「回報碼」整欄複製到剪貼簿不方便時,用這個產生純文字清單,
 * 執行後在「執行紀錄」裡直接複製,貼進老師驗證頁。
 */
function exportCodes() {
  var sh = SpreadsheetApp.getActiveSpreadsheet().getSheetByName(SHEET_NAME);
  if (!sh || sh.getLastRow() < 2) { Logger.log('目前沒有資料'); return; }
  var codes = sh.getRange(2, 6, sh.getLastRow() - 1, 1).getValues()
                .map(function (r) { return String(r[0]).trim(); })
                .filter(String);
  Logger.log(codes.join('\n'));
}

執行後試算表會出現「回報碼」工作表。把回報碼那一整欄複製,貼進本頁最上方的批次驗證即可。

這個驗證碼能證明什麼
碼是由姓名、題組、兩個分數、日期一起算出來的。學生把同學的截圖拿來交、或是把分數修圖改掉,驗證碼都會對不上。

建議的收成績流程
貼上班級名單,沒交的人也會出現在表格裡(紅底標「未回報」),不必再拿名單一個一個核對; 名字打錯或不在名單的回報會另外列出來標「不在名單」,方便您回頭確認是誰。 指派題組可以寫範圍,例如 set01-set30。

請學生用系統首頁的「我的成績總表」產生一行回報碼。回報碼裡帶有每一組的完成日期(第一次對帳的當天), 所以學生什麼時候交都沒關係——只要在上面填「本次指派題組」與「截止日」,表格就會標出誰逾期、誰未交, 不必要求學生在期限內回報。

請學生用系統首頁的「我的成績總表」產生一行回報碼,整學期只交一次(不必每個題組各交一次)。 收集方式可以是 Google 表單一題、班級 Line 群、或郵件;收到之後整欄複製貼進上面的批次驗證, 就會得到一張含各組分數與平均的表格,可一鍵複製到 Excel 登記成績。
